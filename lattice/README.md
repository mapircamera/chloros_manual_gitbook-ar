# كاميرات LATTICE

LATTICE هو نظام الكاميرات متعدد الأطياف القابل للتعديل من MAPIR والمخصص للتصوير الزراعي والعلمي. تعتمد كل كاميرا من كاميرات LATTICE على مستشعر Sony IMX265 ذي الغالق الشامل (**

3.1 ميجابكسل، بكسلات بحجم 3.45 ميكرومتر**) وتتصل عبر شبكة إيثرنت كجهاز**GigE Vision**. يتحكم برنامج

Chloros 1.3.0 في كاميرات LATTICE بشكل مباشر — من خلال اكتشاف الكاميرات، والمعاينة المباشرة، والتقاط الصور، ومصفوفات الكاميرات المتعددة المتزامنة — من خلال ثلاث واجهات:

| الواجهة    | المكان                                                          | المنصات                                                |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| واجهة المستخدم الرسومية (GUI) | علامة التبويب **الكاميرات** في الشريط الجانبي لـ Chloros                         | Windows 10/11 x64                                        |
| واجهة سطر الأوامر (CLI)        | مجموعة أوامر `chloros-cli lattice`                           | Windows 10/11 x64، Linux x86\_64، Linux aarch64 (Jetson) |
| Python SDK | `chloros_sdk.connect_camera()` / `chloros_sdk.connect_array()` | Windows 10/11 x64، Linux x86\_64، Linux aarch64 (Jetson) |

> **هل تبحث عن الأجهزة؟**تم توثيق وحدات الكاميرات، والعدسات، والمرشحات والنطاقات، والإطارات وحوامل التثبيت، والكابلات، و PoE، وأسلاك التشغيل في [**دليل المستخدم الخاص بـ LATTICE**](https://mapir.gitbook.io/lattice-camera). يتناول هذا الفصل تشغيل الكاميرات من خلال Chloros.

تكون لقطات LATTICE عبارة عن ملفات قياسية من نوع `.tif`/`.tiff`، ويقوم Chloros دائمًا بمعالجتها بدءًا من اللقطة الأولية. انظر [مرجع CLI](../reference/cli-reference.md) و[مرجع SDK](../reference/sdk-reference.md) للاطلاع على قائمة الأوامر الكاملة وواجهة برمجة التطبيقات (API).

## تكوينان للمستشعر

| التكوين | المستشعر       | المرشح                                | ما تقدمه الكاميرا الواحدة                                          |
| ------------- | ------------ | ------------------------------------- | ----------------------------------------------------------------- |
| **M3C**| ألوان باير | مرشح ثلاثي النطاقات                |**ثلاثة نطاقات معايرة من تعريض ضوئي واحد**                 |
| **M3M**| أحادي اللون   | مرشح تداخل أحادي النطاق الضيق |**نطاق واحد معاير**؛ دمج عدة كاميرات M3M للحصول على مؤشرات |

نظرًا لأن كاميرا M3M أحادية اللون وتعمل خلف مرشح واحد، يحصل كل نطاق على تعريض ضوئي خاص به. تغطي كاميرا M3C جميع نطاقاتها الثلاثة بتعريض ضوئي واحد للمستشعر.

## سلاسل الطراز والتسمية

تخزن كل كاميرا هويتها في GenICam `DeviceUserID` كسلسلة طراز:

```
<sensor>-<lens>-F<filter>       e.g.  M3C-L41-FRGN,  M3M-L87-F450
```

يعرضها برنامج Chloros مع البادئة `LATT-` (على سبيل المثال `LATT-M3M-L87-F450`). يتم كتابة نفس السلسلة `LATT-…` في علامة EXIF `Model` لكل عملية تصدير، وتُستخدم كاسم مجلد إخراج الكاميرا في المشاريع المعالجة.

| المكون | القيم                                                   | المعنى                                                                                            |
| --------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| المستشعر    | `M3C` / `M3M`                                            | ألوان باير / أحادي اللون                                                                          |
| العدسة      | `L41` / `L87`                                            | الرقم يمثل **مجال الرؤية الأفقي بالدرجات**: L41 = ضيق (41°)، L87 = واسع (87°)    |
| المرشح    | `FRGB` / `FRGN` / `FOCN` / `FNGB` (M3C) أو `F<nm>` (M3M) | انظر [المرشحات والنطاقات الطيفية](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands) |

تحدد سلسلة الطراز كل ما يليها: يقوم برنامج Chloros بتحديد ملف تعريف المستشعر وتخطيط النطاقات والمعايرة المصنعية من `DeviceUserID` + `DeviceSerialNumber`. لا يوجد أي شيء لتكوينه لكل كاميرا — انظر [توصيل الكاميرات](connecting.md).

## المرشحات والنطاقات

تعد مراكز النطاقات وحواف FWHM والكتالوج الكامل لـ 23 SKU M3M من مواصفات المنتج، لذا فهي موجودة في دليل الأجهزة: [**المرشحات والنطاقات الطيفية**](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands).

ما يهم من الناحية البرمجية: يحدد رمز المرشح في سلسلة الطراز المنتجات التي يمكن لـ Chloros إنتاجها. الكاميرات المزودة بمرشحات RGB (`FRGB`) تصدر منتجات بعد إزالة التباين اللوني (debayered) ومنتجات المعاينة فقط — حيث إن الإشعاع والانعكاس لكل نطاق لا معنى لهما بالنسبة لمستشعر عريض النطاق، لذا تتجاهلهما Chloros وتشير إلى ذلك صراحةً. أما كل مرشح آخر فينتج السلسلة الكاملة: الإشعاع → الانعكاس → المؤشر.

## نظرة عامة على المعايرة الإشعاعية

تتم معايرة كل كاميرا من كاميرات LATTICE بشكل فردي في المصنع وفقًا لسلسلة قابلة للتتبع وفقًا لمعايير NIST، وتُشحن مع شهادة خاصة بكل كاميرا. ما تغطيه هذه المعايرة، وكيفية قياسها، والدقة التي يمكنك ذكرها، كل ذلك موجود في دليل الأجهزة: [**المعايرة الإشعاعية في المصنع**](https://mapir.gitbook.io/lattice-camera/calibration/factory-radiometric-calibration).

من ناحية البرمجيات، ما يهم هو أن برنامج Chlorosيحدد المعايرة الصحيحة عند توصيل الكاميرا ويثبت المعاملات المطبقة في كل عملية تصدير — انظر [توصيل الكاميرات](connecting.md).
