# نظرة عامة على نظام Linux

يوفر Chloros 1.3.0 دعمًا أصليًّا لنظام Linux لكل من **CLI**و**Python SDK** — معالجة الصور متعددة الأطياف بدون شاشة، بالإضافة إلى التحكم المباشر في كاميرات LATTICE ومستشعرات الضوء DAQ — على محطات العمل التي تعمل بنظام Linux، والخوادم، وأجهزة الحافة NVIDIA Jetson.

{% hint style="info" %}
**لا توجد واجهة مستخدم رسومية (GUI) على سطح المكتب في نظام Linux.**واجهة المستخدم الرسومية لـ Chloros مخصصة لنظام Windows فقط. يتفاعل مستخدمو Linux مع Chloros من خلال [CLI](../CLI.md) و[Python SDK](../api-python-sdk.md). يضيف `.deb` إدخال**Chloros CLI** إلى قائمة التطبيقات لديك — وهو ببساطة يفتح محاكي محطة طرفية يعمل على `chloros-cli`.
{% endhint %}

## مصفوفة دعم الأنظمة الأساسية

| الميزة | Windows (واجهة المستخدم الرسومية) | Windows (CLI/SDK) | Linux amd64 (CLI/SDK) | Linux arm64 / Jetson (CLI/SDK) |
| --- | --- | --- | --- | --- |
| **واجهة المستخدم الرسومية لسطح المكتب** | نعم | غير متوفر | لا | لا |
| **واجهة سطر الأوامر (CLI)** (`chloros-cli`) | نعم | نعم | نعم | نعم |
| **Python SDK** (`chloros-sdk`) | نعم | نعم | نعم | نعم |
| **مسار معالجة الصور** | نعم | نعم | نعم | نعم |
| **التحكم في كاميرا LATTICE (مباشر)** | نعم (علامة التبويب «الكاميرات») | نعم (`chloros-cli lattice`، SDK) | نعم | نعم |
| **مستشعرات الضوء DAQ (مباشرة)** | نعم (علامة التبويب «مستشعرات الضوء») | نعم (`chloros-cli daq pool-*`، SDK) | نعم | نعم |
| **مزامنة الوقت عبر PTP (المضيف هو الجراندماستر)** | نعم | نعم (`chloros-cli time-sync`) | نعم | نعم |
| **تسريع GPU (CUDA)** | نعم | نعم | نعم | نعم (JetPack 6) |
| **إزالة التباين مع مراعاة النسيج** (تتطلب وحدة معالجة رسومات تدعم CUDA) | نعم (Chloros+) | نعم (Chloros+) | نعم (Chloros+) | نعم (Chloros+) |
| **التكيف الحسابي الديناميكي** | نعم | نعم | نعم | نعم |
| **الخلفية كخدمة نظام** (`chloros-backend@<user>.service`) | لا | لا | نعم (اختياري) | نعم (اختياري) |
| **أداة التحديث المباشر** (`chloros-cli update`) | لا (تشغيل المثبت) | لا (تشغيل المثبت) | نعم | نعم |

## البنى المدعومة

| البنية | الوصف | الحزمة |
| --- | --- | --- |
| **amd64 (x86_64)** | معالجات سطح المكتب/الخوادم القياسية (Intel، AMD) | `chloros_<version>_amd64.deb` |
| **arm64 (aarch64)** | معالجات ARM — عائلة NVIDIA Jetson Orin (JetPack 6) | `chloros_<version>_arm64_jp6.deb` |

## توزيعات **Linux** المدعومة

* **Ubuntu 22.04 LTS أو أحدث** (amd64)
* **Debian 12 أو أحدث** (amd64)
* **NVIDIA JetPack 6** (arm64 — منصات Jetson Orin)

## ما يحصل عليه مستخدمو Linux

* **Chloros CLI** — واجهة سطر الأوامر الكاملة للمعالجة المجمعة والأتمتة وكتابة البرامج النصية
* **Chloros Python SDK** — واجهة Python البرمجية لخطوط الإنتاج البحثية والأدوات المخصصة، يتم تثبيتها بواسطة `.deb` للنظام `python3` (يوجد في `/usr/lib/chloros/sdk/` حزمة «wheel» متوافقة مع الإصدار لـ virtualenvs؛ أما PyPI فهو مخصص للأجهزة التي لا تحتوي على حزمة Chloros)
* **التحكم في كاميرات LATTICE** — اكتشاف كاميرات LATTICE ومصفوفات الكاميرات المتعددة المتزامنة وتوصيلها وتهيئتها والتقاط الصور منها عبر `chloros-cli lattice` وSDK؛ ويضم `.deb` بيئة تشغيل Arena SDK التي تتطلبها الكاميرات
* **التحكم في مستشعرات الضوء DAQ** — قم بتوصيل مستشعرات DAQ-U/M/E، وبث الأطياف المعايرة، وتسجيل ملفات `.daq` عبر `chloros-cli daq pool-*` وSDK
* **مزامنة الوقت عبر PTP** — تعمل الخلفية (Chloros) على تشغيل جهاز PTP الرئيسي الذي تتبع كاميرات LATTICE ومستشعرات DAQ-E إشاراته؛ افحصه باستخدام `chloros-cli time-sync`، وحافظ على تشغيله بدون واجهة مستخدم باستخدام وحدة systemd `chloros-backend@<user>.service` (انظر [تثبيت Linux](linux-installation.md#always-on-ptp-for-headless-hosts))
* **أتمتة المشاريع** — قم بتشغيل المشاريع المحفوظة دون واجهة مستخدم باستخدام `chloros-cli project` و`open_project` الخاص بـSDK
* **تسريع وحدة معالجة الرسومات (GPU)** — معالجة مُسرَّعة بواسطة CUDA على وحدات معالجة الرسومات من NVIDIA (وحدات معالجة الرسومات المكتبية على amd64، ووحدة معالجة الرسومات الخاصة بـ Jetson مع JetPack 6)
* **التكيف الحسابي الديناميكي** — الكشف التلقائي عن الأجهزة واختيار استراتيجية المعالجة، مع استخدام `CHLOROS_STRATEGY` للتجاوز كخيار احتياطي متقدم
* **جميع ميزات المعالجة** — نفس مسار المعالجة المستخدم في نظام Windows: المعايرة، وتصحيح التظليل، ومؤشرات الغطاء النباتي، وجميع تنسيقات التصدير
* **ميزات Chloros+** — معالجة متعددة الخيوط (متسلسلة)، و«Texture Aware debayer» (على وحدة معالجة رسومات CUDA)، ومؤشرات مخصصة، مع اشتراك مدفوع في Chloros+

## ما لا يحصل عليه مستخدمو Linux

* **واجهة المستخدم الرسومية لسطح المكتب** — لا توجد واجهة رسومية؛ تتم جميع عمليات التفاعل عبر واجهة سطر الأوامر (CLI) أو مجموعة أدوات تطوير البرامج (Python SDK)
* **عارض الصور** — لا يوجد عارض صور تفاعلي، أو عرض شبكي، أو علامات خرائط
* **إدارة المشاريع المرئية** — يتم إنشاء المشاريع وتشغيلها عبر أوامر واجهة سطر الأوامر (CLI) واستدعاءات حزمة تطوير البرامج (SDK) (تظل الأجهزة نفسها — الكاميرات، وأجهزة الاستشعار، وأجهزة الالتقاط — قابلة للتحكم الكامل من خلال المحطة الطرفية)

## متطلبات الترخيص

يتطلب الوصول إلى واجهة سطر الأوامر (CLI) ومجموعة أدوات التطوير (SDK) **مستوى Chloros+ مدفوع — Copper أو أعلى**(Copper، Bronze، Silver، Gold). لا يوفر المستوى المجاني**Iron** أي وصول إلى واجهة سطر الأوامر (CLI) أو مجموعة أدوات التطوير (SDK). يتم فرض هذا الحد الأدنى من قبل الخلفية (backend)، وليس فقط عبر واجهة سطر الأوامر (CLI):

| الحالة | استجابة الخلفية |
| --- | --- |
| لم يتم تسجيل الدخول | `401` مع `error_code: AUTH_REQUIRED` |
| مسجل الدخول على فئة Iron المجانية | `403` مع `error_code: PLAN_UPGRADE_REQUIRED` |

يعمل `chloros-cli status` على أي فئة — فهو المسار الوحيد المعفى من البوابة — لذا يكون سبب الرفض مرئيًا دائمًا.

## البدء على Linux

1. **تثبيت Chloros** — انظر [تثبيت Linux](linux-installation.md) لتثبيت `.deb`
2. **التحقق** — يقوم `chloros-cli --version` بطباعة `Chloros CLI 1.3.0`؛ ويقوم `chloros-cli selftest` بتشغيل التشخيص المكون من 7 خطوات
3. **تحقق من Python SDK** — يقوم `.deb` بتثبيته: `python3 -c "import chloros_sdk; print(chloros_sdk.__version__)"` (في بيئة virtualenv، `pip install /usr/lib/chloros/sdk/chloros_sdk-*.whl`)
4. **تسجيل الدخول** — `chloros-cli login your@email.com 'your-password'` (مرة واحدة لكل جهاز؛ تحديثات الحزمة تحافظ على بيانات تسجيل الدخول، وإزالة الحزمة تمحوها)
5. **معالجة مجموعة البيانات الأولى** — `chloros-cli process ~/datasets/flight001`

بالنسبة لـ NVIDIA Jetson، راجع [دليل NVIDIA Jetson](nvidia-jetson-guide.md) المخصص للإعداد الخاص بالمنصة، والسلوك الحراري، والنشر الميداني.
