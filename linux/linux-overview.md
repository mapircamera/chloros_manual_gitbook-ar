# نظرة عامة على Linux

يوفر الإصدار Chloros 1.1.0 دعمًا أصليًا لـ **CLI**و**Python SDK**، مما يتيح معالجة الصور متعددة الأطياف بدون شاشة على محطات العمل Linux والخوادم وأجهزة NVIDIA Jetson الطرفية.

{% hint style="info" %}
**لا توجد واجهة مستخدم رسومية على Linux.** تتوفر واجهة المستخدم الرسومية لسطح المكتب Chloros على Windows فقط. يتفاعل مستخدمو Linux مع Chloros من خلال [CLI](../CLI.md) و[Python SDK](../api-python-sdk.md).
{% endhint %}

***

## مصفوفة دعم المنصات

| الميزة | Windows (GUI) | Windows (CLI/SDK) | Linux amd64 (CLI/SDK) | Linux arm64 / Jetson (CLI/SDK) |
| --- | --- | --- | --- | --- |
| **واجهة المستخدم الرسومية لسطح المكتب** | نعم | غير متوفر | لا | لا |
| **CLI** | نعم | نعم | نعم | نعم |
| **Python SDK** | نعم | نعم | نعم | نعم |
| **تسريع GPU (CUDA)** | نعم | نعم | نعم | نعم (JetPack 6) |
| **إزالة التمويه مع مراعاة النسيج** | نعم (Chloros+) | نعم (Chloros+) | نعم (Chloros+) | نعم (Chloros+) |
| **التكيف الحسابي الديناميكي** | نعم | نعم | نعم | نعم |***

## البنى المدعومة

| البنية | الوصف | طريقة التثبيت |
| --- | --- | --- |
| **amd64 (x86_64)** | معالجات سطح المكتب/الخادم القياسية (Intel، AMD) | حزمة `.deb` |
| **arm64 (aarch64)** | المعالجات القائمة على ARM، وبشكل أساسي NVIDIA Jetson | حزمة `.deb` (JetPack 6) |

## توزيعات Linux المدعومة

* **Ubuntu 20.04+** (amd64)
* **Debian 11+** (amd64)
* **NVIDIA JetPack 6** (arm64 — منصات Jetson)***

## ما يحصل عليه مستخدمو Linux

* **Chloros CLI** — واجهة سطر أوامر كاملة للمعالجة المجمعة والأتمتة وكتابة البرامج النصية
* **Chloros Python SDK** — واجهة Python البرمجية (`pip install chloros-sdk`) للتكامل مع مسارات البحث والأدوات المخصصة
* **تسريع GPU** — معالجة معجلة بواسطة CUDA على وحدات معالجة الرسومات (GPU) من NVIDIA (أجهزة سطح المكتب وJetson)
* **التكيف الحسابي الديناميكي** — الكشف التلقائي عن الأجهزة وتحسين استراتيجية المعالجة
* **جميع ميزات المعالجة** — نفس مسار المعالجة متعدد الأطياف مثل Windows (المعايرة، تصحيح التظليل، مؤشرات الغطاء النباتي، جميع تنسيقات التصدير)
* **ميزات Chloros+** — معالجة متعددة الخيوط، وإزالة التباين مع مراعاة النسيج، ومؤشرات مخصصة (مع ترخيص Chloros+)

## ما لا يحصل عليه مستخدمو Linux

* **واجهة المستخدم الرسومية لسطح المكتب** — لا توجد واجهة رسومية؛ تتم جميع التفاعلات عبر CLI أو Python SDK
* **عارض الصور** — لا يوجد عارض صور تفاعلي، أو عرض شبكي، أو علامات خرائط
* **إدارة المشاريع المرئية** — تتم إدارة المشاريع عبر أوامر CLI ومكالمات SDK***

## البدء في استخدام Linux

1. **تثبيت Chloros** — انظر [تثبيت Linux](linux-installation.md) لتثبيت حزمة `.deb`
2. **تثبيت Python SDK** (اختياري) — `pip install chloros-sdk`
3. **تنشيط الترخيص** — `chloros-cli login your@email.com 'password'`
4. **معالجة مجموعة البيانات الأولى** — `chloros-cli process ~/datasets/flight001`

بالنسبة لمستخدمي NVIDIA Jetson، راجع [دليل NVIDIA Jetson](nvidia-jetson-guide.md) المخصص للإعداد والتحسين الخاص بالمنصة.
