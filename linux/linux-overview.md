# نظرة عامة على Linux

يوفر Chloros 1.2.0 دعمًا أصليًا لـ Linux لـ **CLI**و**Python SDK** — معالجة الصور متعددة الأطياف بدون شاشة، بالإضافة إلى التحكم المباشر في كاميرا LATTICE ومستشعر الضوء DAQ — على محطات العمل Linux والخوادم وأجهزة الحافة NVIDIA Jetson.

{% hint style="info" %}
**لا توجد واجهة مستخدم رسومية (GUI) لسطح المكتب على Linux.**واجهة المستخدم الرسومية لسطح المكتب Chloros متوفرة حصريًّا على Windows. يتفاعل مستخدمو Linux مع Chloros من خلال [CLI](../CLI.md) و[Python SDK](../api-python-sdk.md). يضيف `.deb`**Chloros CLI** إلى قائمة التطبيقات الخاصة بك — بل يفتح ببساطة محاكي محطة طرفية يعمل بـ `chloros-cli`.
{% endhint %}

## البنيات المدعومة

| البنية | الوصف | الحزمة |
| --- | --- | --- |
| **amd64 (x86_64)** | معالجات سطح المكتب/الخوادم القياسية (Intel، AMD) | `chloros_<version>_amd64.deb` |
| **arm64 (aarch64)** | معالجات ARM — عائلة NVIDIA Jetson Orin | `chloros_<version>_arm64_jp6.deb` (إصدار JetPack 6) |

## توزيعات Linux المدعومة

* **Ubuntu 22.04 LTS أو أحدث** (amd64)
* **Debian 12 أو أحدث** (amd64)
* **NVIDIA JetPack 6** (arm64 — منصات Jetson Orin)***

## ما يحصل عليه مستخدمو Linux

* **Chloros CLI** — واجهة سطر الأوامر الكاملة للمعالجة المجمعة والأتمتة وكتابة البرامج النصية
* **Chloros Python SDK** — واجهة Python البرمجية لمسارات البحث والأدوات المخصصة (قابلة للتثبيت من PyPI، ومُضمّنة أيضًا داخل `.deb` كملف wheel متوافق مع الإصدار)
* **التحكم في كاميرات LATTICE** — اكتشاف كاميرات LATTICE ومصفوفات الكاميرات المتعددة المتزامنة وتوصيلها وتهيئتها والتقاط الصور منها عبر `chloros-cli lattice` وSDK؛ يحتوي `.deb` على بيئة التشغيل Arena SDK التي تتطلبها الكاميرات
* **التحكم في مستشعرات الضوء DAQ** — قم بتوصيل مستشعرات DAQ-U/M/E، وبث الأطياف المعايرة، وتسجيل ملفات `.daq` عبر `chloros-cli daq pool-*` و SDK
* **مزامنة الوقت عبر PTP** — تعمل الخلفية Chloros على تشغيل «الجراندماستر» (grandmaster) لـ PTP الذي تتبع كاميرات LATTICE ومستشعرات DAQ-E إيقاعه؛ افحصه باستخدام `chloros-cli time-sync`، واستمر في تشغيله دون واجهة مستخدم باستخدام وحدة systemd `chloros-backend.service` (انظر [تثبيت Linux](linux-installation.md#always-on-ptp-for-headless-hosts))
* **أتمتة المشاريع** — قم بتشغيل المشاريع المحفوظة دون واجهة مستخدم باستخدام `chloros-cli project` ووحدة `open_project` التابعة لـ SDK
* **تسريع وحدة معالجة الرسومات (GPU)** — معالجة مُسرَّعة بواسطة CUDA على وحدات معالجة الرسومات (GPU) من NVIDIA (أجهزة سطح المكتب وJetson)
* **التكيف الحسابي الديناميكي** — الكشف التلقائي عن الأجهزة واختيار استراتيجية المعالجة، مع إمكانية تجاوز الإعدادات باستخدام `CHLOROS_STRATEGY` كخيار احتياطي متقدم
* **جميع ميزات المعالجة** — نفس مسار المعالجة المستخدم في Windows: المعايرة، وتصحيح التظليل، ومؤشرات الغطاء النباتي، وجميع تنسيقات التصدير
* **ميزات Chloros+** — معالجة متعددة الخيوط (متسلسلة)، وإزالة التباين مع مراعاة النسيج (Texture Aware debayer)، ومؤشرات مخصصة، مع خطة Chloros+ المدفوعة

## ما لا يحصل عليه مستخدمو Linux

* **واجهة المستخدم الرسومية لسطح المكتب** — لا توجد واجهة رسومية؛ تتم جميع عمليات التفاعل عبر CLI أو Python SDK
* **عارض الصور** — لا يوجد عارض صور تفاعلي، أو عرض شبكي، أو علامات على الخريطة
* **إدارة المشاريع بصريًا** — يتم إنشاء المشاريع وتشغيلها عبر أوامر CLI ومكالمات SDK (تظل الأجهزة نفسها — الكاميرات، وأجهزة الاستشعار، وأجهزة التقاط الصور — قابلة للتحكم الكامل من المحطة الطرفية)***

## متطلبات الترخيص

يتطلب الوصول إلى CLI و SDK **فئة Chloros+ مدفوعة — فئة «كوبر» أو أعلى**(كوبر، برونز، فضي، ذهبي). لا تتيح الفئة المجانية**Iron** الوصول إلى CLI/SDK. يتم فرض الحد الأدنى من قبل الخادم الخلفي، وليس فقط من خلال CLI:

| الحالة | استجابة الخادم الخلفي |
| --- | --- |
| غير مسجل الدخول | `401` مع `error_code: AUTH_REQUIRED` |
| مسجل الدخول على المستوى المجاني Iron | `403` مع `error_code: PLAN_UPGRADE_REQUIRED` |

يعمل `chloros-cli status` على أي فئة — فهو المسار الوحيد المعفى من البوابة — لذا فإن سبب الرفض يكون مرئيًا دائمًا.

## البدء في استخدام Linux

1. **تثبيت Chloros** — انظر [تثبيت Linux](linux-installation.md) لمعرفة كيفية تثبيت `.deb`
2. **التحقق** — يقوم `chloros-cli --version` بطباعة `Chloros CLI 1.2.0`؛ ويقوم `chloros-cli selftest` بتشغيل التشخيص المكون من 7 خطوات
3. **تثبيت Python و SDK** (اختياري) — `pip install chloros-sdk`
4. **تسجيل الدخول** — `chloros-cli login your@email.com 'your-password'` (مرة واحدة لكل جهاز، ومرة أخرى بعد كل ترقية للحزمة)
5. **معالجة مجموعة البيانات الأولى** — `chloros-cli process ~/datasets/flight001`

بالنسبة لـ NVIDIA Jetson، راجع [دليل NVIDIA Jetson](nvidia-jetson-guide.md) المخصص للإعداد الخاص بالمنصة، والسلوك الحراري، والنشر الميداني.
